Keandalan Sistem & Edge Case:

Jika server n8n atau WhatsApp API sedang down/offline, sistem backend menggunakan asinkron try-catch dengan timeout 4 detik. Status DELAY tetap tersimpan aman di Database SQLite & Excel, dan dashboard tetap merender warna merah tanpa error/crash.

Sinyal Terputus di Dock!

Request Timeout - ACT TIME Belum Tersimpan

Pemberitahuan Driver:

Koneksi sinyal HP Anda terputus atau melebihi batas waktu (timeout) saat berada di Dock.

⚠️ WAKTU AKTUAL (ACT TIME) BELUM TERCATAT!

Silakan pastikan sinyal HP Anda kembali stabil, lalu tekan ulang tombol UPDATE ACT TIME. Waktu aktual yang tercatat adalah waktu saat sinyal berhasil terkirim ke server.
